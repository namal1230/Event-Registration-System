# Event Registration System

A simple web application for managing event registrations built with core PHP and MySQL.

## 📋 Project Overview

The Event Registration System is a web-based application that allows administrators to create and manage events, and employees to register for events. The system includes user authentication, event management, and registration tracking features.

**Language:** PHP  
**Database:** MySQL  
**Created:** June 22, 2025
